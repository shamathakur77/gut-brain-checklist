# Gut & Brain Checklist — deploy

Drag-and-drop ready for Vercel.

## To put it live (2 minutes)
1. Go to vercel.com and log in
2. Click "Add New" then "Project"
3. Drag this whole folder (or the unzipped contents) into the import area
   - Or: drag the folder straight onto vercel.com if you're already logged in
4. Click Deploy. Done. You get a URL like gut-brain-checklist.vercel.app

No build settings needed. It's a single static page.

## To add it to your phone home screen
- iPhone: open the URL in Safari, tap Share, "Add to Home Screen"
- Android: open in Chrome, tap the menu (3 dots), "Add to Home screen"
It opens fullscreen with a gold star icon, like an app.

## What's inside
- index.html — the whole tool, self-contained. Nothing else needed.
